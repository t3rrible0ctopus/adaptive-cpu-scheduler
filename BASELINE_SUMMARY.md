# Initial Classical Baseline Summary (30 matched seeds)

This is a simulator smoke/baseline experiment, not the RL evaluation. Each policy receives identical generated workloads for each workload type, load level, and seed. Metrics are averaged across 30 seeds.

## Interpretation caveats

- These are synthetic workloads generated by the current code, not real OS traces.
- SJF is non-preemptive and is given the next CPU burst length in advance, so it is an idealized baseline.
- The priority scheduler is preemptive and uses lower numeric values as higher priority.
- The Round Robin quantum is 3 simulation ticks. Changing it can materially change RR results.
- These averages alone do not establish statistical significance; paired confidence intervals should be added for the paper.
- The Jain index currently uses CPU demand divided by turnaround as a service-rate proxy; do not call it a definitive fairness measure without validating the formulation.
- Scheduling decision overhead is currently accounted separately and is not inserted into simulated time.
